## Issues Encountered

- **The `#[forbid(unsafe_code)]`-vs-tests conflict** — the allocator's pin tests use unsafe arena constructions, which a module-level forbid would reject. Resolved by moving the tests byte-verbatim to a crate-root `#[cfg(test)]` module (`port/src/allocator_tests.rs`) — the forbid cascades down module trees, and the crate root is not under `allocator`. The cfg(test) corruption hook needed by the tripwire test is safe index manipulation (no unsafe) inside the forbidden module — the index model makes even the test hook safe.
- **The MntIo Send supertrait** broke the unmodified host tests (FakeServer's Rc fid table) — resolved by homing `unsafe impl Send for MntCore` beside BusyCell in the exempt floor module.
- **This nightly's `SyncUnsafeCell<T>: Sync` requires `T: Sync`** (not Send) — the QuickFit static needed `unsafe impl Sync` (documented, homed in the shim).
- **The OneRetry-worthy trap:** `cargo xtask build` defaulting to x86_64 (see deviation 5).
