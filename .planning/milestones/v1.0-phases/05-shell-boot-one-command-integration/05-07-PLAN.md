phase's hinge gate: boot(8) COMPLETES on r9, init runs, newns parses the shipped namespace,

environment — per-process namespaces now include a mounted 9P tree served by a userspace server

Output: devmnt + sys_fversion/sys_mount + the boot-to-prompt-print gate.
