<objective>
The Harvey-side supply chain for the real boot chain: an additive, objtype-gated aarch64 build
for `boot(8)` (the one binary with no standalone mkfile — its method table is normally
awk-generated from a kernel config, RESEARCH Pattern 2), the extension of the proven subset
build to `init`/`paqfs`/`stacksmoke`, the paqfs image root-tree skeleton (scoped termrc +
namespace + mount-point dirs, D-05/D-08), the bake script, and the dev-time qemu launcher the
next six plans' gates drive.

Purpose: every kernel-side gate from 05-04 onward consumes a baked image containing the real
chain; landing the supply chain first keeps those plans on kernel work. No r9-side files are
touched here — this plan is pure Harvey userland/image tooling.
Output: out/{boot,init,paqfs,stacksmoke} aarch64 binaries, root-tree/ skeleton, bootfs.paq,
run-r9.sh.

(the first task that can run end-to-end — it consumes this plan's image) because D-14 locks
debug-first (05-01) and the measure-first trace (05-03) is carried-forward locked policy.
